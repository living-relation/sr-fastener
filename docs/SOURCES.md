# Dimension sources

Generated by `tools/build_catalog.py` from the catalog. Every value in a family comes from the sources
listed for it; `tests/test_sources.py` spot-checks rows against them. Blank or TBD means not sourced.

For a part McMaster sells, the model uses McMaster's dimensions. The standard or maker sheet is the cross-check.
Inch and metric of one type share one shop smart code (SSH for both socket head screws). That code starts the
Fusion part number. A McMaster number in the table is for ordering only. It is never the Fusion part number.
A value like 91855A is the McMaster series already cited for that family, not one line per size.
PEM press-in parts use the PEM designation (S-M4-1ZI, FHS-M5-12). They are not shop smart codes, and they
have no McMaster column. The hex pocket depth is not listed: it is only for looks.
